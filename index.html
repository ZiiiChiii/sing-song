還差一步：設定 Firebase

這個遊戲用 Firebase Realtime Database 讓主螢幕和學生設備即時連線。請打開這個 HTML 檔，找到最上方的 FIREBASE_CONFIG，把你的 Firebase 設定貼進去。

  1. 到 Firebase 主控台建立新專案（例如 music-game）。
  2. 左側「建構 → Realtime Database」→ 建立資料庫（位置選新加坡 asia-southeast1）。
  3. 在「規則」分頁貼上下方規則並發布。
  4. 專案設定 → 一般 → 新增網頁應用程式，複製 firebaseConfig（包含 databaseURL）。
{
  "rules": {
    "rooms": {
      "$room": { ".read": true, ".write": true }
    }
  }
}
